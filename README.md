# Attime.in - Official Website

Pro landing website for Attime.in - Smart Attendance, Simplified

## Pages
- index.html - Home / Landing
- about.html - About us
- pricing.html - Pricing plans
- contact.html - Contact & Demo
- privacy.html - Privacy Policy
- terms.html - Terms

## Setup (GitHub Pages)
1. Upload all files to main branch of udayprajapati-ngo/attime repo
2. Keep CNAME file as is (attime.in)
3. Settings > Pages > Branch: main, folder: /root
4. Wait 2-3 mins, site auto deploys
